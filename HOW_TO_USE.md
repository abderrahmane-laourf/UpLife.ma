## 🚀 Getting Started

### First Time Setup

1. **Register Account**
   - Open the app
   - Click "Register" / "Sign Up"
   - Enter your phone number (Moroccan format: +212...)
   - Enter your full name
   - Create a password
   - Verify OTP code sent via WhatsApp
   - ✅ Account created!

2. **Login**
   - Enter your phone number
   - Enter your password
   - Click "Login"
   - You're in! 🎉

3. **Initial Configuration**
   - Go to **Settings** → **Categories Tab**
   - Default categories are pre-loaded (Fitness, Meditation, Learning, etc.)
   - Add custom categories if needed

## ✅ Activities Management

Navigate to **Activities** page to manage your daily tasks.

### Creating Activities

1. Click **"+ Add Activity"** button
2. Fill in the form:
   - **Title:** Task name (e.g., "Morning Workout")
   - **Description:** Optional details
   - **Category:** Select from your categories
   - **Prayer Status:** For prayer-related activities (optional)
3. Click **"Save"**

### Managing Activities

#### Complete a Task
- Click the ✓ checkbox next to the task
- Task moves to "Completed" section
- Confetti animation appears! 🎉

#### Uncomplete a Task
- In "Completed" section, uncheck the task
- Task moves back to "Today's Activities"

#### Edit a Task
- Click **Edit** button (pencil icon)
- Modify any field
- Click **"Update"**

#### Delete a Task
- Click **Delete** button (trash icon)
- Confirm deletion
- Task is removed

### Date Navigation

**View activities from any date:**
- Click **Previous Day** (←) to go back
- Click **Next Day** (→) to go forward
- Click **Today** button to jump to current date
- Date picker shows selected date

### Missed Activities

**Missed tasks** are activities you didn't complete yesterday (moved by "Slit Nhar" action).

#### Managing Missed Tasks:

1. **View Missed Activities**
   - Scroll to "Missed Activities" section
   - See all tasks you missed

2. **Edit Missed Task**
   - Click **Edit** button
   - Update title/description
   - Add reason why you missed it
   - Click **"Update Missed Activity"**

3. **Delete Missed Task**
   - Click **Delete** button
   - Confirm deletion

4. **Restore Missed Task** ⭐
   - Click **"Restore"** button
   - Task moves to "Completed" section
   - Use this if you actually did the task but forgot to mark it!

### Slit Nhar (Reset Day)

**What it does:**
- Takes ALL unfinished tasks from TODAY
- Moves them to "Missed Activities"
- Clears today's pending list
- Fresh start for a new day! 🌅

**When to use:**
- End of day before going to bed
- When starting a new day
- To clean up your task list

**How to use:**
1. Click **"Slit Nhar"** button on Dashboard or Activities page
2. Confirm action
3. Done! All incomplete tasks are now in "Missed"

## 🎯 Goals & Milestones

Set long-term wellness objectives and break them into actionable steps.

### Creating a Goal

1. Go to **Settings** → **"My Goal"** tab
2. Click **"Edit"** or form appears if no goal exists
3. Fill in:
   - **Goal Title:** Your main objective (e.g., "Lose 5 kg before summer")
   - **Description:** Details about your goal
   - **Category:** Select relevant category
   - **Target Deadline:** Optional date
4. Click **"Save Goal"**

### Managing Your Goal

#### Edit Goal
- Click **"Edit"** button
- Modify any field
- Click **"Save Goal"**

#### Complete Goal
- Click **"✓ Complete"** button
- Goal is marked as achieved! 🎉
- Congratulations message appears

#### Delete Goal
- Click **"Delete"** button
- Confirm deletion
- Goal is removed

### Partial Goals (Steps/Milestones) ⭐

**Break your main goal into smaller, manageable steps!**

#### Adding Steps

1. In "My Goal" tab, scroll to **"Steps to Achieve"** section
2. Click **"+ Add Step"** button
3. Modal opens:
   - **Step Title:** What you need to do (e.g., "Join a gym")
   - **Description:** Optional details
4. Click **"Add"**
5. Step appears in the list!

#### Managing Steps

**Toggle Completion:**
- Click the checkbox next to a step
- Checked = completed ✓
- Progress bar updates automatically!

**Edit Step:**
- Hover over step
- Click **Edit** icon (appears on hover)
- Modify title/description
- Click **"Update"**

**Delete Step:**
- Hover over step
- Click **Delete** icon (appears on hover)
- Confirm deletion

### Progress Tracking

The **progress bar** shows:
- Number of completed steps (e.g., 3/5)
- Percentage complete (e.g., 60%)
- Visual bar that fills as you complete steps

**Auto-Complete Feature:** 🎉
- When you check off the LAST incomplete step
- System automatically marks the main goal as complete!
- Celebration message appears
- All your hard work paid off!

**Example Flow:**
```
Goal: Lose 5 kg
Steps:
☐ 1. Join a gym
☐ 2. Exercise 3x per week
☐ 3. Follow meal plan
☐ 4. Drink 2L water daily
☐ 5. Track weight weekly

Progress: 0/5 (0%)
[░░░░░░░░░░░░░░░░░░░░]

(You check off step 1)
✓ 1. Join a gym
☐ 2. Exercise 3x per week
...

Progress: 1/5 (20%)
[████░░░░░░░░░░░░░░░░]

(You check off all remaining steps)

Progress: 5/5 (100%)
[████████████████████]

🎉 Main goal auto-completes!
"Congratulations! All steps completed! Goal achieved!"
```

## 💡 Tips & Best Practices

### For Activities

✅ **DO:**
- Add activities in the morning for the day ahead
- Use descriptive titles
- Assign correct categories
- Use "Slit Nhar" daily to reset
- Review missed activities regularly
- Restore tasks if you forgot to mark them

❌ **DON'T:**
- Add too many activities (keep it realistic!)
- Forget to complete tasks as you finish them
- Ignore missed activities
- Skip daily resets

### For Goals

✅ **DO:**
- Set SMART goals (Specific, Measurable, Achievable, Relevant, Time-bound)
- Break goals into 3-7 steps
- Update progress regularly
- Celebrate small wins
- Set realistic deadlines

❌ **DON'T:**
- Set vague goals
- Create too many partial goals
- Forget to update step completion
- Give up if you miss a deadline

### For Reviews

✅ **DO:**
- Write daily reviews
- Be honest in reflections
- Note specific achievements
- Identify patterns
- Use reviews to improve

❌ **DON'T:**
- Skip reviews
- Write generic reflections
- Ignore challenges
- Forget lessons learned

### For Categories

✅ **DO:**
- Create 5-10 relevant categories
- Use clear, descriptive names
- Pick distinct colors
- Organize by life areas

❌ **DON'T:**
- Create too many categories
- Use similar names/colors
- Delete categories in use

## 🆘 Troubleshooting

### Can't Login
- Check phone number format (+212...)
- Verify password
- Request password reset if needed

### Activities Not Showing
- Check date filter (might be viewing wrong date)
- Refresh page
- Clear browser cache

### Goal Not Saving
- Ensure all required fields filled
- Check category is selected
- Try refresh and save again

### Steps Not Auto-Completing Goal
- Verify ALL steps are checked ✓
- Refresh page
- Check goal is still active
